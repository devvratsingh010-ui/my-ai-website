# HisabAI - Indian Kachha Bill Scanner & Sales Tracker

**HisabAI** is a web application designed specifically for Indian small shopkeepers (Kirana stores, general merchants, dairies) to upload photos of handwritten or printed *kachha bills* and automatically track their sales and items sold.

---

## 1. Supported Languages (Strictly 4 Languages)

HisabAI strictly supports exactly four bill languages:

1. **English (`en`)**
2. **Hindi (`hi`)** — हिंदी (Devanagari script)
3. **Kannada (`kn`)** — ಕನ್ನಡ (Kannada script)
4. **Telugu (`te`)** — తెలుగు (Telugu script)

All other language options have been removed from the language selector, OCR configuration, and onboarding flows.

### Language Capabilities:
- **Auto-Detection (`auto`)**: Automatically analyzes character Unicode script distribution to detect whether a bill is in English, Hindi, Kannada, or Telugu.
- **Manual Pre-Selection**: The shopkeeper can select any of the four supported languages or choose *Auto-detect* before scanning.
- **Mixed-Script Support**: Seamlessly recognizes bills mixing English headers/numbers with Hindi, Kannada, or Telugu item names.
- **Original Script Preservation**: Item names are always preserved in their original script (e.g., `चीनी`, `ಸಕ್ಕರೆ`, `చక్కెర`). They are never automatically translated into English.
- **Unsupported Language Warnings**: If text in an unsupported script (e.g. Tamil, Bengali, Arabic) is detected, the system displays a clear warning banner and provides a manual correction fallback.
- **Native Digit Normalization**: Converts native numerals (Devanagari `०-९`, Kannada `೦-೯`, Telugu `౦-౯`) to standard Arabic numerals (`0-9`) for arithmetic validation.

## 2. OCR Architecture (Google Cloud Vision OCR)

HisabAI integrates with **Google Cloud Vision OCR** using document-oriented text detection (`DOCUMENT_TEXT_DETECTION`).

### Features:
- **Language Hints**: Pass targeted language hints (`["hi", "kn", "te", "en"]`) based on user selection to maximize OCR accuracy for regional scripts.
- **Image Preprocessing**:
  - **EXIF Orientation Correction**: Automatically fixes rotated camera photos via `PIL.ImageOps.exif_transpose`.
  - **Blur & Readability Detection**: Computes edge gradient sharpness via Laplacian/Sobel edge analysis to warn shopkeepers about blurry or unreadable photos.
  - **Contrast & Sharpness Enhancement**: Boosts contrast for faint pencil or ballpoint pen handwriting.
  - **Dimension & Size Normalization**: Resizes massive images while keeping high resolution for OCR.
  - **SHA-256 Content Hashing**: Generates unique hashes to prevent duplicate bill submissions.
- **Security**: Backend-only API key / service account handling. Secret credentials are never exposed to the browser.
- **Graceful Error Handling**:
  - `CREDENTIALS_MISSING`: Clear notification with configuration instructions while maintaining full manual entry and representative test bills.
  - `QUOTA_EXCEEDED` (HTTP 429): Informs user of rate limits with manual fallback.
  - `SERVICE_UNAVAILABLE` (HTTP 503 / Timeouts): Graceful timeout handling.
  - `NO_TEXT`: Clear message when an image is blank or unreadable.

## 3. Structured Bill Parsing & Math Validation

OCR extracts raw text; `app/parser/bill_parser.py` converts that text into structured fields:
- **Item Name**: In original recognized script.
- **Quantity & Unit**: Recognizes metric and Indian units (`kg`, `g`, `ltr`, `ml`, `packet`, `pcs`, `box`, `bag`, `dozen`, `किलो`, `लीटर`, `पैकेट`, `ಕೆಜಿ`, `ಲೀಟರ್`, `కేజీ`, `లీటరు`).
- **Unit Price / Rate**: Identified via `@ rate` or rate columns.
- **Line Total**: Validated against `quantity * unit_price`.
- **Bill Date**: Parses Indian date formats (`DD/MM/YYYY`, `DD-MM-YY`, `YYYY-MM-DD`).
- **Bill Number**: Extracts memo or invoice numbers.
- **Subtotal, Tax, Discount, Grand Total**: Computed and cross-verified.

### Strict Accounting Rules:
- Missing fields are left as `null` / empty; numbers are **never silently invented**.
- If a line has a quantity but no price (or vice versa), it is flagged for shopkeeper review.
- Arithmetic is verified: if `quantity * rate != line_total` or `sum(items) - discount + tax != grand_total`, discrepancies are highlighted with clear explanations without altering original extracted text.
- Standardized product names are suggested via `product_aliases` while keeping the original item name untouched.

## 4. Side-by-Side Bill Verification Screen

After scanning, the shopkeeper sees:
- **Left Panel**: Original bill photo preview, image sharpness badge, and a toggle to inspect raw OCR text.
- **Right Panel**: Fully editable bill document:
  - Edit bill number and date.
  - Edit item names in original script.
  - Edit quantities, units, and rates.
  - Highlighted warning borders (`flagged-input`) on uncertain or mismatched fields.
  - Add missing item rows or delete incorrect rows.
  - Live arithmetic recalculation of subtotal and grand total.
  - Duplicate bill warning if an identical image or metadata exists in the shop's records.
  - **Confirm & Save Button**: Bills are only saved after explicit shopkeeper verification.

---

## 5. Sales Dashboard & Multi-Tenancy

- **Real-Time KPIs**:
  - Today's Sales (₹) & Bill Count
  - Last 7 Days Sales (₹)
  - Current Month Sales (₹)
  - All-Time Sales (₹) & Total Verified Bills Count
- **Item-Wise Sales Breakdown**: Aggregates items sold by quantity and revenue, displaying original script names.
- **Recent Bills & Bills History**: View, edit, or delete bills.
- **Instant Recalculation**: Editing or deleting any bill immediately recalculates dashboard totals and item-wise sales.
- **Row-Level Security (RLS)**: Strict database tenant isolation by `shop_id`. Shop A can never see or affect Shop B's records.
